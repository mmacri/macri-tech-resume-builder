# mikemacri.com

Technology and Customer Success Engineering leadership portfolio for Michael “Mike” Macri, MBA. The application is built with React, TypeScript, Vite, Tailwind CSS, React Router, and Lucide icons.

## Local development

```sh
npm install
npm run dev
```

## Validation

```sh
npm test
npm run lint
npx tsc --noEmit
npm run build
```

## Career content

Active website career facts are maintained in `src/data/careerData.ts`. Education and recognition are maintained in `src/data/resume/`. Avoid hard-coding dates, titles, metrics, or role descriptions in page components.

The downloadable résumé uses `public/resume-source.md` and is generated by:

```sh
npm run generate:resume
npm run verify:resume
```

`public/resume-source.md` is the editable résumé source, `scripts/generate-resume-pdf.mjs` creates the canonical `public/resume.pdf`, and `scripts/verify-resume-pdf.mjs` inspects the generated PDF bytes, page count, selectable text, current-role facts, and stale positioning. Always commit `public/resume.pdf` with its source update. The broader content-integrity test also checks the current GitLab role, March 2026 date, leadership scope, contact policy, and absence of the former simulated contact success flow.

## Contact delivery

No production form-delivery service or secure serverless endpoint is configured. The Contact page therefore uses LinkedIn as the reliable contact method and truthfully states that direct form delivery is unavailable.

To enable a form later:

1. Configure a secure serverless endpoint or managed form provider.
2. Keep provider credentials server-side; do not expose secrets through Vite client variables.
3. Add spam protection and server-side rate limiting.
4. Return explicit success and failure responses.
5. Add a test proving success is shown only after a successful response.

## Routing and deployment

`public/_redirects` defines permanent legacy-route redirects before the SPA fallback on compatible static hosts. The post-build script also creates canonical, noindex static redirect pages for hosts that do not honor redirect rules. React Router provides the final client-side compatibility layer. See `PUBLIC-FOOTPRINT-CLEANUP.md` for the route inventory, exact host limitations, and post-deployment verification steps.

`public/_headers` requests revalidation for `/resume.pdf` and identifies `/resume.pdf` as the canonical PDF resource. Hosts that ignore static header files require equivalent CDN/hosting configuration.

## Post-deployment checklist

1. Deploy the production build and verify `https://mikemacri.com` is the canonical domain.
2. Verify direct loading for `/leadership`, `/experience`, `/selected-work`, `/projects`, `/resume`, `/about`, and `/contact`.
3. Verify `https://mikemacri.com/resume.pdf` contains GitLab as the current employer, March 2026 as the start date, and the broader Technology & Customer Success Engineering positioning.
4. Submit `https://mikemacri.com/sitemap.xml` in Google Search Console.
5. Request re-indexing for the homepage, Leadership, Experience, Selected Work, Projects, Resume, and About pages.
6. Request a re-crawl of the résumé PDF where available.
7. Monitor older indexed snippets and allow search engines time to refresh them; deployment alone does not guarantee immediate re-indexing.
